# Criminal Face Identification System

A Java Swing desktop application for managing criminal records using MySQL and OpenCV.

## Features

- Add criminal records
- Search criminal records
- Update and delete records
- Upload criminal images
- Store data using MySQL
- Face detection using OpenCV
- Face recognition functionality in progress

## Technologies

- Java
- Java Swing
- MySQL
- OpenCV
- JDBC
